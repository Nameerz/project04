Digital Playground – Personal Portfolio

About the Project

Digital Playground is my personal portfolio website, created to showcase my skills, projects, hobbies, and contact information. The website uses a modern, futuristic design with a dark navy background and neon green accents.

This project was developed using HTML5, CSS3, and JavaScript (ES6).

Features

* Home: Introduction and welcome section.
* About Me: Information about me and my interests.
* Skills: Displays my technical skills, including HTML, CSS, JavaScript, and Git/GitHub.
* Projects: Showcases four projects, numbered 00–03, with links to view each project.
* Hobbies: Displays my personal interests, including football, technology, gaming, and music.
* Contact: Provides my phone number and email address, with clickable buttons to call me or send an email.
* Theme Switcher: Allows users to switch between dark and light themes.
* Responsive Design: Adapts the layout to different screen sizes, including mobile phones, tablets, and desktops.
* Animations: Includes hover effects and scroll reveal animations.
* Navigation Menu: Provides easy navigation between the website sections.

Technologies Used

* HTML5 – Website structure and content.
* CSS3 – Styling, Flexbox, Grid, animations, and responsive design.
* JavaScript (ES6) – Theme switching, mobile navigation, active navigation links, and scroll animations.
* Git and GitHub – Version control and project sharing.

How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all the files and the assets folder are in the correct locations.
4. Open index.html using the Live Server extension, or open it directly in a web browser.
5. Navigate through the website using the navigation menu.

Customization

You can customize the portfolio by:

* Updating the About Me section.
* Adding or removing skills.
* Replacing the example projects with real projects.
* Adding links to project repositories or live websites.
* Changing the hobbies and descriptions.
* Updating the phone number and email address.
* Modifying the colors and styles in style.css.

Contact

The Contact section contains my phone number and email address. Visitors can use the Call Me and Send Email buttons to contact me.
